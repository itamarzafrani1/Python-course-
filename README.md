# מסלול פייתון — גרסת Mobile/PWA

החבילה מוכנה להעלאה כאתר סטטי. חשוב להעלות את **כל הקבצים באותה תיקייה**.

## מה תוקן

- `index.html` בשם הנכון, כדי שה-manifest וה-service worker ימצאו אותו.
- מגרש המשחקים לא מפעיל יותר קיצורי ניווט בזמן כתיבה: `/`, החצים וכתיבת קוד בתוך textarea נשארים בעורך.
- התאמה למקלדת של טלפון: `100dvh`, safe-area, גלילה פנימית, כפתור הרצה נגיש ותיבות קוד בגודל טקסט שלא גורם ל-iOS לבצע zoom.
- יעדי מגע גדולים יותר, תפריט צד מותאם למסכים צרים וניווט שיעורים שנערם במסכים קטנים.
- Brython מקובע לגרסה `3.14.3` כדי למנוע שבירה מעדכון CDN עתידי.
- ה-service worker שומר את Brython לאחר ההרצה הראשונה, כך שהמנוע הקל יכול לעבוד אופליין לאחר שנטען פעם אחת.
- Pyodide נשאר מנוע אופציונלי "מלא". הוא כבד משמעותית ולכן לא נשמר אוטומטית במטמון במובייל.
- קיצור PWA ל"מגרש משחקים" דרך `?playground=1`.
- Portrait ו-Landscape נתמכים.

## הרצה מקומית

PWA ו-Service Worker דורשים HTTP/HTTPS. מתוך התיקייה:

```bash
python -m http.server 8080
```

ואז פתח:

```text
http://localhost:8080
```

## בטלפון

1. העלה את התיקייה ל-Netlify / GitHub Pages / כל hosting סטטי עם HTTPS.
2. פתח ב-Safari או Chrome.
3. iPhone: Share -> Add to Home Screen.
4. Android: Install app / Add to Home screen.

## מנועי הקוד

- ברירת מחדל: **Brython / mini-pytest** — קל יותר ומתאים לטלפון.
- אופציונלי: **Pyodide** — CPython מלא וכבד יותר; מומלץ בעיקר במחשב או במכשיר עם מספיק RAM.

לבדיקת אופליין של המגרש: פתח פעם אחת את מגרש המשחקים כשיש אינטרנט, הרץ קוד פשוט, סגור את האתר, נתק אינטרנט ופתח שוב.
